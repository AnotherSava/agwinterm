No complete reference for agwinterm's config, keymap or control API is checked in as markdown. Each
one is a string constant compiled into the app, which is why grepping the repo for a config key or a
verb finds a prose mention at best:

- **Config reference** — `TerminalConfig.DefaultText` in `src/Agwinterm.Core/TerminalConfig.cs`
  (~line 209). One commented block per key, ~60 keys. This is what seeds
  `%LOCALAPPDATA%\agwinterm\agwinterm.conf` on first run, and it is the only complete key list.
- **Keymap reference** — `Keymap.StarterText` in `src/Agwinterm.Win32/Keymap.cs` (~line 67): chord
  grammar, run modes, `{AGW_*}` tokens. Default bindings are the `DefaultBindings` array above it.
- **Control-API reference** — `AgentSkill.SkillMarkdown` in `src/Agwinterm.Pty/AgentSkill.cs`
  (~line 14). The full `agwintermctl` verb set; installed to `~/.claude/skills/agwinterm/SKILL.md`
  and the `.codex` equivalent by `agwintermctl install skill`.
- **F1 help** — `src/Agwinterm.Win32/Help.cs`, built at runtime from the *effective* keymap.
- **Settings dialog** — six tabs built in `BuildSettingsRows()` in `src/Agwinterm.Win32/Settings.cs`
  (~line 89): General, Appearance, Notifications, Agent Status, Key Mapping, Profiles.
- **README.md** — the product pitch: what it does, the object model, install, `agwintermctl`
  examples, and a Documentation section linking everything below. Building from source and running a
  dev build beside the release moved to `CONTRIBUTING.md` in #293 (2026-09-14).

Since #293 `docs/` holds **both kinds of file**, and the README's Documentation section is what
separates them. Linked from it, and maintained: `user-guide.md` (agent features, the terminal,
accessibility, themes, keybindings, config paths), `control-api.md`, `session-commands.md`,
`navigation.md`, `quick-terminal.md`, `session-hud.md`, `native-picker.md`, `defterm-testing.md`,
and the two parity tables `agterm-parity.md` and `lite-parity.md`. Everything the README does not
link is **archaeology**: dated agterm and Windows Terminal gap analyses, a roadmap, the defterm
feasibility note, a memory profile, the AGWin bitmap report, `plans/`, `specs/` and `superpowers/`.
Read an unlinked file as a record of what someone thought at its date — see [[agwinterm-doc-gaps]]
for which parts have gone stale.

There is no CHANGELOG, SECURITY file, issue template, or docs site; release notes are GitHub
auto-generated by `.github/workflows/release.yml`.
